☕ v2.0.3 — 2026-11-24

  • Changed: after your link is created, the message now stays 2 s (was 3 s) before opening the board / リンクを作ったあとのお知らせを 3 秒 → 2 秒に
  • Changed: press OK to go to the board right away — no more waiting / OK を押すと、待たずにすぐ集計ボードへ

🏆 v2.0.2 — 2026-11-24

  • New: open with ?title= and ?desc= to pre-fill the event name and description (e.g. from a tournament bracket) / リンクでイベント名と説明を入れた状態で開けるように
  • New: 🏆 "Make a tournament bracket" link under the board (MeridiPlay) / 集計ボードの下に大会の組み合わせ作りへの入り口
  • New: a small ☕ thank-you note after your link is created; the message now stays 3 s (was 1.5 s) before opening the board / リンクを作り終えたときに小さく ☕、お知らせを 1.5 秒→3 秒表示
  • New: ☀️ Light mode for everyday use (button at top right; remembered on this device. Matrix Green dark stays the default) / ふだん使い向けのライト表示（右上のボタン、この端末に記憶。最初はこれまでどおりダーク）
  • Changed: time slots are now listed in time order, for everyone and in every time zone (older events are re-sorted when opened; answers stay matched) / 時間枠を時刻順に並べる（前に作った予定も開いたときに並べ直し、回答はずれない）
  • New: 🔗 "Copy link" on the board, to share the event again later / 集計ボードからリンクをもう一度コピー
  • New: 👑 head count on each time slot (⭕ 3 · 🔺 1) / 時間枠ごとに ⭕ と 🔺 の人数
  • New: 🌍 "Show my time" switches the board between the organizer's time and your own (remembered) / 集計ボードを主催者の時間⇔自分の時間に切り替え（端末に記憶）
  • New: 📅 "Add to calendar" for the 👑 BEST slot — makes a small .ics file on the spot (no server). Pick the length (30 min–3 h). Opens in each person's own time zone / BEST の時間を .ics でカレンダーへ（その場で作る・長さを選べる・海外では現地時間に）
  • New: ⌨️ answer with the keyboard: 1 ⭕ · 2 🔺 · 3 ✖️, ↑↓ to move (on computers) / パソコンでは 1・2・3 キーで回答、↑↓ で移動
  • Changed: 📱 bigger ⭕🔺✖️ buttons and full-width tools on phones / スマホで ⭕🔺✖️ を大きく、ボタンを横いっぱいに
  • Fixed: names and comments are now shown as plain text, so typed symbols such as < > can't break the board / 名前・コメントに記号を入れても表が崩れないように
